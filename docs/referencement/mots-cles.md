# Mots-clés visés et suivi des positions Google (depuis le 12/10/2026)

Objectif de l'utilisateur (12/10/2026) : « que mon site soit dans les 3 premières pages de Google quand les gens
tapent les sujets que je traite », c'est-à-dire une position de 1 à 30.

Une seule page par recherche. Le mot-clé principal est le champ `mot_cle` de l'article. Les variantes plus
longues sont moins disputées et donc atteignables plus tôt pour un site neuf. Le niveau de difficulté est une
estimation, pas une mesure : aucun outil gratuit ne donne la difficulté ; la réalité se lira dans la Search
Console. Pour les mots courts (« charge mentale », « nerf vague », « routine du soir »), la concurrence vient
des grands médias santé : viser d'abord les variantes.

## Méthode de suivi (déclencheur « Suivi positions Google », chaque vendredi)

1. Lire dans la Search Console les requêtes, la position moyenne et les impressions par page, sur les 28 derniers jours.
2. Repérer les pages en position 11 à 40 avec des impressions : ce sont les plus proches des 3 premières pages,
   et donc la priorité.
3. Pour ces pages, améliorer sans rien inventer :
   - reprendre telle quelle, dans un intertitre ou une question fréquente, la formulation exacte que les gens tapent, si elle n'y est pas ;
   - compléter la réponse si une source vérifiée le permet ;
   - ajouter des liens internes depuis les articles proches ;
   - revoir le titre seulement si le taux de clic est très bas pour la position.
4. Ne jamais changer l'adresse d'une page. Ne pas bourrer de mots-clés.
5. Noter chaque semaine une ligne dans le tableau ci-dessous.
